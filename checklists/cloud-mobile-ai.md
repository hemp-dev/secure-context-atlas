# Cloud/mobile/AI checklist

- Map identities, permissions, storage, network egress, provider APIs, device components, model context, retrieval, memory and tools.
- Check least privilege, tenant/data classification, signing/provenance, secure storage, exported components, update paths and logging.
- Treat document/text/tool/model output as untrusted data; enforce authorization, schema and capability controls outside the model.
- Use policy simulators, emulators, local model stubs, test projects and mocks; avoid production side effects.
