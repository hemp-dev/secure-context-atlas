# Web/API checklist

- Inventory routes, methods, schemas, versions, deprecated hosts, GraphQL resolvers, gRPC methods, WebSockets and webhooks.
- Check authentication lifecycle, object/property/function/tenant/transaction authorization at the decision point.
- Trace request, headers, cookies, files, URLs and third-party responses through parsers, templates, queries, redirects and HTTP clients.
- Check browser origin/CSRF/CORS/CSP, proxy/cache/desync, error handling, rate/resource limits and audit events.
- Validate with test users/tenants, synthetic canaries, staging and negative regression tests.
