# TypeScript

Types disappear at runtime. Inspect validators at the boundary, type assertions, `any`, unsafe casts, discriminated unions, decorator/reflection paths, `JSON.parse`, raw SQL, `innerHTML`, URL fetch and tool-call arguments.

Use runtime schemas, exhaustive validation, branded identifiers for tenant/object separation, parameterized APIs and typed capability objects. Do not treat a compile-time interface or generated OpenAPI type as authorization.
