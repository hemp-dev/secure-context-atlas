# Rust

Safe Rust reduces memory risk but does not prevent authorization, SSRF, injection, unsafe deserialization, path, logic or supply-chain issues. Inspect `unsafe`, FFI, `Command`, templates, SQL, URL clients, archive parsers and `serde` flatten/untagged enums.

Use typed domain identifiers, validated structs, parameterized queries, bounded clients, explicit capabilities, checked arithmetic and minimal `unsafe` blocks with invariants. Audit build scripts and procedural macros as code-execution boundaries.
