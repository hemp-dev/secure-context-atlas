# CI/CD and SCM

Inventory event triggers, branch/tag protection, workflow permissions, runner trust, action/plugin references, secrets, caches, artifact stores, signing, deploy identities and environment approvals.

Separate untrusted pull requests from release jobs, use ephemeral least-privilege runners, pin dependencies/actions/images, bind artifacts to source, verify signatures and mask secrets. Validate in a disposable fork/project or dry-run.
