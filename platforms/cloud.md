# Cloud

Inventory accounts/projects/subscriptions, workload identity, IAM/resource policies, metadata endpoints, storage, queues, serverless triggers, secrets, private/public routes and egress. Trace user-controlled URLs and file content to cloud APIs.

Look for wildcard permissions, public data, cross-account trust, ambient credentials, unbounded egress, default encryption/retention and logs containing PII/secrets. Validate with a test account/project and policy simulator or dry-run where available.
