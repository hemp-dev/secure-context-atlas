# Internal enterprise and Active Directory

Inventory identity protocols, trust relationships, service accounts, delegation, LDAP/Kerberos/NTLM/SMB paths, admin interfaces, DNS/name resolution, endpoints and logging. Model relay, downgrade and credential exposure as trust-boundary questions.

Check signing/channel binding, least privilege, constrained delegation, tiering, default credentials, service isolation and audit coverage. Use a dedicated lab domain and synthetic identities; never probe a production domain from this repository.
