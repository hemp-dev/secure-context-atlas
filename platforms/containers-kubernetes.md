# Containers and Kubernetes

Inventory images, registries, Dockerfiles, entrypoints, users, capabilities, mounts, namespaces, service accounts, admission, NetworkPolicy, secrets, probes and host/runtime versions.

Check root/privileged/host namespaces, writable rootfs, broad tokens, mutable tags, unbounded egress, exposed dashboards and build-to-deploy artifact binding. Use static manifest checks and an isolated cluster; do not test breakout against shared infrastructure.
